# CLI overview

```text
vertox scan       Solidity/Vyper source scan
vertox build      Foundry/Hardhat build helper
vertox fetch      Download runtime bytecode
vertox inspect    Contract and proxy intelligence
vertox reverse    EVM disassembly and CFG
vertox selectors  ABI selector tools
vertox storage    Storage-slot inspection
vertox rpc        Raw JSON-RPC
vertox network    Network configuration
```

Use `vertox <command> --help` for complete arguments.
