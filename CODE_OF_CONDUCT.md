# Code of conduct

VERTOX contributors are expected to keep technical discussion respectful, specific, and focused on the work.

Harassment, threats, discriminatory abuse, deliberate disruption, and publication of another person's private information are not acceptable in project spaces.

Maintainers may edit, hide, or remove contributions that violate these expectations and may restrict participation when needed to protect the project community.

If you need to report conduct privately, contact the repository maintainer through a private channel listed on the maintainer's GitHub profile.
